## Архитектурные решения

### State Management - BLoC
**Почему выбран BLoC:**
- Четкое разделение бизнес-логики и UI
- Тестируемость
- Reactive programming с Streams
- Масштабируемость для больших проектов
- Официальная поддержка Flutter команды

**Альтернативы рассмотренные:**
- Riverpod - хорош, но BLoC более зрелый
- Provider - проще, но менее структурирован для больших проектов

### Local Storage - Hive
**Почему выбран Hive:**
- Быстрый (pure Dart, без native dependencies)
- Легковесный
- Type-safe с адаптерами
- Отличная производительность
- Простая миграция данных

**Альтернативы:**
- Drift (sqflite) - более мощный, но сложнее
- Isar - быстрее, но менее стабилен

### Network - Dio
**Почему выбран Dio:**
- Interceptors для логирования/auth
- Отмена запросов
- Timeout конфигурация
- FormData поддержка
- Широкое использование в сообществе

## Демонстрация оффлайн-режима

### Сценарий демонстрации:

1. **Запуск с интернетом:**
   - Приложение загружает данные с сервера
   - Индикатор "Online" (зеленая иконка)

2. **Работа онлайн:**
   - Создать задачу → мгновенная синхронизация
   - Задача помечена как "synced"

3. **Отключение интернета:**
   - Включить режим полета
   - Индикатор меняется на "Offline" (серая иконка)
   - Кнопка синхронизации скрывается

4. **Работа оффлайн:**
   - Создать 2-3 новые задачи
   - Редактировать существующую задачу
   - Удалить задачу
   - Все операции работают
   - Задачи помечены как "Not synced"

5. **Включение интернета:**
   - Выключить режим полета
   - Индикатор меняется на "Online"
   - Появляется кнопка синхронизации

6. **Синхронизация:**
   - Нажать кнопку синхронизации
   - Показать прогресс
   - Snackbar: "Synced X tasks"
   - Все задачи теперь "synced"

## Проблемы и решения

### Проблема 1: Синхронизация конфликтов
**Решение**: Стратегия "сервер побеждает" - серверные данные имеют приоритет

### Проблема 2: Производительность списка
**Решение**: Использование ListView.builder для ленивой загрузки

### Проблема 3: Реактивные обновления
**Решение**: Stream из Hive box для автоматических обновлений UI
