# Planner+ - Быстрый старт

## Как запустить проект

### Предварительные требования
- Flutter SDK 3.0.0 или выше
- Dart SDK 3.0.0 или выше

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/Dimanchick22/Flutter.git
cd Flutter
```

2. **Переключитесь на нужную ветку:**
```bash
git checkout claude/planner-plus-app-011CUPnsLBq25YvYFF47zGLh
```

3. **Установите зависимости:**
```bash
flutter pub get
```

4. **Запустите приложение:**
```bash
flutter run
```

## Демонстрация оффлайн-режима

### Пошаговая инструкция:

1. **Запустите приложение с интернетом:**
   - Убедитесь, что интернет включен
   - Запустите `flutter run`
   - Обратите внимание на зеленую иконку "Online" в правом верхнем углу

2. **Создайте несколько задач онлайн:**
   - Нажмите кнопку "+" внизу экрана
   - Заполните поля (название обязательно)
   - Выберите приоритет
   - Добавьте теги
   - Сохраните задачу
   - Задачи синхронизируются автоматически

3. **Отключите интернет:**
   - Включите режим полета на устройстве
   - Иконка изменится на серую "Offline"
   - Кнопка синхронизации исчезнет

4. **Работайте оффлайн:**
   - Создайте новые задачи
   - Отредактируйте существующие
   - Отметьте задачи как выполненные
   - Удалите задачу
   - Все изменения сохраняются локально
   - Несинхронизированные задачи помечены чипом "Not synced"

5. **Включите интернет обратно:**
   - Выключите режим полета
   - Иконка вернется к зеленой "Online"
   - Появится кнопка синхронизации

6. **Синхронизируйте изменения:**
   - Нажмите кнопку синхронизации (иконка sync)
   - Дождитесь завершения
   - Увидите уведомление "Synced X tasks"
   - Все задачи теперь синхронизированы

## Основные функции

### Управление задачами:
- **Создание**: Кнопка "+" → заполните форму → "Create Task"
- **Редактирование**: Нажмите на задачу → измените данные → "Update Task"
- **Удаление**: Откройте задачу → кнопка корзины → подтвердите
- **Отметка выполненной**: Нажмите checkbox слева от задачи

### Фильтрация и поиск:
- **Фильтры**: All / Pending / Completed (сегментированная кнопка)
- **Сортировка**: Кнопка меню → By Date / By Title / By Priority
- **Группировка**: Кнопка меню → No Grouping / By Priority / By Status / By Date
- **Поиск**: Кнопка поиска → введите текст → результаты в реальном времени

### Настройки:
- **Тема**: Settings → Theme → выберите Light / Dark / System
- **Язык**: Settings → Language → выберите English / Русский

## Структура проекта

```
lib/
├── core/                   # Общая функциональность
│   ├── di/                # Dependency Injection
│   ├── errors/            # Обработка ошибок
│   ├── router/            # Навигация
│   └── theme/             # Темы приложения
├── data/                   # Слой данных
│   ├── datasources/       # Источники данных (local, remote)
│   ├── models/            # Модели данных
│   └── repositories/      # Реализации репозиториев
├── domain/                 # Бизнес-логика
│   ├── entities/          # Сущности
│   ├── repositories/      # Интерфейсы репозиториев
│   └── usecases/          # Варианты использования
└── presentation/           # UI
    ├── bloc/              # State management
    ├── screens/           # Экраны
    └── widgets/           # Виджеты
```

## Технологический стек

- **State Management**: flutter_bloc

- **Network**: Dio

- **DI**: get_it
